# Hrimfell ↔ Skyrim name map

Hrimfell uses original names in the game: no names, places or texts are taken from Bethesda's games. This file
records which Skyrim place, person, item or idea each in-game thing stands for, so the next location can be
looked up on UESP / Fandom under its Skyrim name and built under its Hrimfell name.

Status:
- **in game**: placed and named in the game.
- **placed**: the model stands, but the name isn't used in the game yet.
- **planned**: in docs/WORKPLAN.md.

Names marked **(proposed)** are new suggestions for things not built yet; they can still be changed.
Code: city coordinates are metres in the city frame (`Wx/Wz`, main gate facing west at (-58,-11)); see WORKPLAN.md for positions.

## Enemies and their drops (v0.4.16)
Enemies keep their Skyrim names too (the user's call, 2026-10-18): Draugr (was "Barrow Wight"), Troll (was "Cave Troll"),
Wolf, Skeleton. The draugr's blade is the Ancient Nord Sword (was "Barrow Blade"); Frost Mirriam (was "Frost Lichen").
Drops follow Skyrim: wolves a Wolf Pelt, trolls Troll Fat, draugr gold and sometimes an Ancient Nord Sword or a potion,
skeletons Bone Meal. Ash-Wing stays: it is a named dragon (our own story), not a kind of enemy.
